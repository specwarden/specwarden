# node-ts playground

`repository/` pretends to be an ordinary small TypeScript library — `slugline`, with a
`lint` and a `test` script of its own — the plainest repository the template is for.

`.specwarden/` there is exactly what `init --template node-ts` writes today: generated by
`node scripts/playgrounds.mjs --write node-ts`, never edited by hand.

## What each defect proves

| Check | Plants | Says |
| --- | --- | --- |
| `secret-scan` | an access key pasted into a source file | `src/client.ts` |
| `doc-paths` | the README naming a source file that was renamed | `src/slug.ts` |
| `lint` | a stray `console.log` the house linter refuses | `npm run lint` |
| `unit` | a regression the library's own tests catch | `npm test` |

## Regenerating

After changing the template: `pnpm --filter @specwarden/template-node-ts build`, then
`node scripts/playgrounds.mjs --write node-ts` — review the `.specwarden/` diff before
committing it.
