# agentic playground

`repository/` pretends to be a service most of whose commits are written by agents: a
role roster under `repository/.claude/agents/`, a router (`repository/AGENTS.md`, `repository/CLAUDE.md`), an active plan
with a decision log, and an archived plan with its harvest header — the kind of
repository where a stale path is not an inconvenience but a wrong action taken
confidently.

`.specwarden/` there is exactly what `init --template agentic` writes today: generated by
`node scripts/playgrounds.mjs --write agentic`, never edited by hand.

## What each defect proves

| Check | Plants | Says |
| --- | --- | --- |
| `agent-definitions` | a leaf reviewer that was given the power to spawn | `reviewer.md` |
| `doc-paths` | the architecture naming a limiter file that was renamed | `src/limits/window.ts` |
| `decision-log-shape` | a rejected alternative with its reason cut off | `a fixed one-minute window` |
| `plan-shape` | a phase sized in days instead of stated as a dependency | `sizes work` |
| `plan-staleness` | an active plan whose branch was merged and deleted — the work landed, the plan stayed | `burst-allowance` |

Beside the checks, the PERIMETER this template writes is proved directly (not through
`provePlayground`, since a perimeter policy is not a check no `check` run ever reaches):
fed the payload Claude Code's `PreToolUse` hook sends, it blocks a force-push with exit 2
naming `no-force-push`, lets an ordinary push through, and fails OPEN — exit 0 — on a
payload it cannot even parse as JSON.

## Regenerating

After changing the template: `pnpm --filter @specwarden/template-agentic build`, then
`node scripts/playgrounds.mjs --write agentic` — review the `.specwarden/` diff before
committing it.
