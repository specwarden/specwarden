# The Northwind platform handbook

Everything the platform team writes down, in one place.

| Section                                                  | For                                         |
| -------------------------------------------------------- | ------------------------------------------- |
| [Your first week](./docs/onboarding/first-week.md)       | a new joiner, before touching anything      |
| [Runbooks](./docs/runbooks/README.md)                    | whoever is on call, at three in the morning |
| [Decisions](./docs/decisions/0001-handbook-lives-in-git.md) | anyone asking "why is it like this"      |

A page that names a path — `docs/runbooks/restart-the-queue.md`, say — names one that
exists. The handbook is checked on every merge, so a moved runbook breaks the build rather
than the next incident.
