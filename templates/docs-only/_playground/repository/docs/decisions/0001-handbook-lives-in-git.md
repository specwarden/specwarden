# 0001 — the handbook lives in git

**Status:** accepted

The handbook moved out of the wiki because a wiki page could reference a runbook that no
longer existed, and nobody found out until they needed it. In git every page is reviewed,
and every path a page names is checked on merge.

**Rejected:** keeping the wiki and linting it nightly — the report arrived in a channel
nobody read, and a nightly check that nobody reads is not a check.
