# Runbooks

One page per operation, each written by somebody who has run it.

- [Restart the queue](./restart-the-queue.md) — the consumer is wedged and lag is climbing.
- [Rotate a credential](./rotate-a-credential.md) — a token leaked, or its calendar ran out.

A runbook starts with the symptom, not with the system. Whoever opens it at three in the
morning knows what they are seeing, not what is causing it.
