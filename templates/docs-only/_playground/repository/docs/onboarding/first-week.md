# Your first week

1. Read the on-call runbook index in `docs/runbooks/README.md` — you will not be paged in
   week one, but you will shadow somebody who is.
2. Read [why the handbook lives in git](../decisions/0001-handbook-lives-in-git.md). It
   explains why a pull request, and not a wiki edit, is how a page changes.
3. Pair on one runbook step. `docs/runbooks/restart-the-queue.md` is the usual first one:
   short, safe, and needed every week.

Ask in the team channel before editing a runbook you have not run yourself.
