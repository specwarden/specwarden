# @specwarden/plugin-nestjs

⬡ **plugin** — NestJS conventions, declared against the engine's primitives.

Module decomposition and the database barrier: a module reaches persistence through a repository, never through a direct ORM import.

## What a plugin is

One stack's conventions, declared against the engine's primitives. Wired from the consumer's config; it never supplies a port adapter.

## Install

```bash
npm install @specwarden/plugin-nestjs specwarden
```

It depends on [`specwarden`](https://github.com/specwarden/specwarden/tree/main/core#readme).
