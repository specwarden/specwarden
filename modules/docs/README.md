# @specwarden/docs

▸ **module** — Documentation checks: paths, symbols, counts, placement, hygiene.

Every path a document names resolves, every symbol it cites exists, and no count is restated where the repository already owns it.

## What a module is

An opinion a repository chooses. It could be wrong about a repository that has never heard of it, which is exactly why it is not in the engine.

## Install

```bash
npm install @specwarden/docs specwarden
```

It depends on [`specwarden`](https://github.com/specwarden/specwarden/tree/main/core#readme).
